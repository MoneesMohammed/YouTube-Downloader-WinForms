# YouTube Downloader - WinForms

A simple desktop application built with **C#** and **Windows Forms** that allows users to download YouTube videos easily.

## Features

- Download YouTube videos using a video URL.
- Simple and user-friendly interface.
- Supports multiple video qualities.
- Displays download progress.
- Uses **yt-dlp** for downloading videos.
- Uses **FFmpeg** for video/audio processing.

## Technologies Used

- C#
- Windows Forms (.NET Framework)
- yt-dlp
- FFmpeg
